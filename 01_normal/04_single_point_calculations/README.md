# Single Point Calculations & Electronic Coupling
#### Computed using the OpenMX software package

1. Generate the template file
 - The template file `nbt.dat` was generated using the <a href="https://www.openmx-square.org/viewer/index.html" target="_blank">OpenMX Viewer</a> that is generated by using a `.cif` file.
 - The template file is then edited to remove the atomic coordinates section, band path section, as well as the flags for both dos calculations and band path calculations at the end of the file.
 - The flag `HS.fileout          on` is added. In my case, I added it to the bottom of the file, but you can add it to the top as well under the initial configuration area (around line 13)
2. Split the trajectory from the MD step into it's individual points using the `split-trajectory.py` file.
- This splits the `XDATCAR` file generated by VASP.
3. Run OpenMX via the `submit_openmx.sh` file
   - This will take multiple days/weeks
   - Compute at least 2ps of single point calculations
4. Run the e-coupling via the `run-e-coupling.py` file in conjunction with the `submit_python.sh` file
   - For other systems, you will need to change:
       - `ntot`: number of atoms in your system
       - `frag_a`: the fragment containing the interactions you want to observe (in this case this would be the PbI structure, as well as interacting Nitrogen atoms and their full organic spacers)
       - `homo`: the HOMO of the structure, which can be found by examining the band occupations located in the VASP `OUTCAR` file
       - `*_ele` and `*_ao`: the ranges for each atom, located in the `XDATCAR` file (at the top, most likely lines 6 & 7) and the atomic orbital pseudopotentials, which can be found in the `POTCAR` file
     - This will take a day or two to compute
5. Plot the e-coupling via the `plot_ecoupling.py` file in conjunction with the `submit_python.sh` file.
     - This will take a short time to compute (less than 1 hour)
